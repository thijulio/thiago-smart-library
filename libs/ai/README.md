# AI boundary

This library is intentionally reserved for future AI capabilities. L1 adds no provider, model, retrieval, or data-access implementation here.

The future [ChatGPT connection direction](../../docs/product/chatgpt-connection.md)
uses the user's authorized ChatGPT account, with no API-key fallback in the
current product scope. Hosted eligibility and implementation remain pending.
The library's canonical records and user actions must work without AI.
