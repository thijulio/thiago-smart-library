# Product documentation

This folder owns the product specification: purpose, intended experience, requirements and product decisions. These documents describe what Smart Library should do; they do not establish implementation or production availability.

| Page                                        | Purpose                                                       |
| ------------------------------------------- | ------------------------------------------------------------- |
| [Overview](overview.md)                     | Product purpose, principles and scope                         |
| [User experience](user-experience.md)       | Intended journeys and behavior                                |

| [Decisions](decisions.md)                   | Confirmed choices and unresolved design questions             |

Use the [roadmap](../roadmap/README.md) for order and dependencies, and GitHub delivery tickets for implementation work and acceptance evidence. Database specifications and detailed execution plans keep their existing technical ownership under `docs/database/` after DB-00 integration; this folder does not replace them.
