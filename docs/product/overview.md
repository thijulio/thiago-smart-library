# Product overview

Thiago Smart Library is a private, durable record of books, reading activity, notes, opinions and
preferences. It replaces the Thiago Library prototype once it offers every prototype capability
and the Google Sheet is no longer written to.

## Principles

- Records survive AI outages, disconnection and provider changes.
- Owner-authored content and generated or inferred content stay distinguishable.
- AI output identifies the records or sources it used.
- Inferred preferences are reviewable before they count as personal truth.
- Enrichment follows explicit actions and never blocks recording them.

## How it is used

Daily capture happens in ChatGPT or Claude through the Smart Library MCP server. The browser
offers the catalog, Reading/Up Next, Stats, Favorites, recaps, an editor and Book Battle. Signed in,
the owner sees everything; visitors see the catalog view.
