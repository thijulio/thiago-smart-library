## Required policy judgments

1. Blank/absent/invalid source means preserve, including nullable members of atomic groups.
   No deletion/archive is inferred from source disappearance. Stable Book IDs are never generated.
2. Baselines represent accepted SOURCE observations. A reviewed keep-database or clear can
   leave a different canonical value; future unchanged source must preserve that decision.
   Changed source can require new review. Conflicts do not silently advance ordinary baselines.
3. Accepted assessments are preserved on changed source unless explicitly reviewed replacement
   allows it; replacement resets review. Native/source metadata and SQL hashes remain distinct.
4. Sentinel spellings are unavailable. Nonblank series without reviewed hash-bound policy are
   quarantined, not guessed. Formula cache use needs exact reviewed cell locators. Reviewer
   metadata is operator-supplied, not cryptographically authenticated.
5. Scope/core/config participates in replay identity. Applied replay returns the original report
   after native edits without replanning or canonical writes. Later scopes are staged/pending;
   this implementation rejects enrichment/events invocation rather than implementing DB-03.
6. Failed canonical work rolls back as a unit; raw staging survives. Failure audit is separate.
   A concurrent committed applied outcome wins over a later failed attempt. Sequence gaps are valid.
7. Extraction conservatively rejects all merges/large row extents and unsupported ZIP layouts;
   standard-path XML serial evidence is required before typed-date canonical use.
